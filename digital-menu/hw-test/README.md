# 하드웨어 시험 도우미 (hw-test)

11/30~12/10 실기기 시험(POS기 i3-6006U Windows 10 Pro, RK3568 TV 보드, PSW-P80 프린터, USB 키패드)을 시험표대로 진행하고 결과를 자동으로 남기는 도구입니다.

- 기계가 볼 수 있는 것은 스크립트가 직접 검사합니다: 서버 응답, 작업 스케줄러, 방화벽, 절전·업데이트 설정, 폴더 권한, TV 관리 API(목록·원격 캡처·보고값·다시 켜진 시간), adb(보드 정보·권한·꺼짐 기록·메모리·와이파이), 번호 부르기 부하, 72시간 연속 기록.
- 사람이 봐야 하는 것은 한 단계씩 보여 주고 **통과/실패**를 묻습니다. 실패면 한 줄 설명을 받고, 화면 사진(POS 화면, TV 원격 캡처)을 같이 저장합니다.
- 끝나면 `report.md`(실패 정리, 위험 점검표에 넣을 상태 값, 개발 스레드에 보낼 글)와 압축 파일을 만듭니다.

시험 항목의 기준본은 `hw-tests.json`이고, 인쇄용 시험표는 [`../docs/hw-test/시험표.md`](../docs/hw-test/시험표.md)입니다. H 번호는 [위험 점검표](../docs/risk-register.md)의 하드웨어 시험 표와 같습니다.

## 준비물

1. 이 `hw-test` 폴더를 POS기에 복사합니다(예: `C:\MenuBoard\hw-test`). 저장소를 통째로 받아도 됩니다.
2. **adb**: [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)의 Windows 압축 파일을 받아 `hw-test\tools\platform-tools\` 에 풉니다(`hw-test\tools\platform-tools\adb.exe` 가 되게). Android SDK가 깔린 PC면 그대로 찾아 씁니다. adb가 없으면 adb 검사만 건너뜁니다.
3. 메뉴판 서버가 설치된 POS기(`C:\MenuBoard\server`, [설치 안내서](../docs/install-pos.md) 기준). 다른 폴더면 `-ServerDir` 로 알려 줍니다.
4. **매장 계정**(사장님 이메일·비밀번호): TV 목록·캡처·번호 부르기에 씁니다. A/S 연결(adb)을 열 때는 **A/S 관리자**(`as@poswing.local`, 설치 때 기록한 비밀번호)를 묻습니다. 비밀번호는 파일에 남기지 않습니다.
5. 정전·공유기·손님 와이파이 시험(H-1, H-8, H-14, H-15)용 **노트북** 한 대(같은 폴더 복사).

## 실행

POS기에서 `run-hw-test.bat` 을 더블클릭합니다. 관리자 권한(UAC)을 묻으면 **예**를 누릅니다.

```
무엇을 할까요?
   [1] 준비: 앱 빌드·TV 설치·TV 확인  (11/30(월) 오전)
   [2] 설치 묶음과 POS기 설정  (11/30(월) 오후)
   [3] TV 보드 기본(설정 저장·부팅·회전·사진)  (12/1(화))
   [4] 전원·재부팅·네트워크  (12/2(수)~12/3(목))
   [5] 번호 호출·키패드·로그인  (12/4(금))
   [6] 부하·연속 운영(72시간)  (12/7(월)~12/10(목))
   [A] 자동 검사만 빠르게(POS기 설정·서버·TV 상태, 5분)
   [H] 항목 번호로 고르기 (예: H-13,H-3)
   [M] 연속 운영 기록 시작(H-5, 72시간)
```

- 각 단계에서 할 일과 **합격 기준**이 나옵니다. 하고 나서 Enter → 자동 검사가 있으면 돌고, 없으면 `P`(통과) / `F`(실패) / `S`(건너뜀) / `I`(기록만)를 누릅니다.
- 시간을 재는 단계는 숫자를 넣거나, **Enter만 누르면 초시계**가 시작되고 다시 Enter로 멈춥니다.
- `Q` 로 언제든 멈출 수 있고, 다시 실행하면 "끝나지 않은 시험이 있습니다. 이어 할까요?"가 나옵니다.
- **POS기를 다시 켜는 단계**(H-25 ②, H-2, H-16, H-12)는 스크립트가 "다시 켜고 로그인하면 이어집니다"를 등록해 둡니다. 다시 켜고 로그인하면 창이 저절로 떠서(UAC 예) 다음 단계로 갑니다.
- 바로 항목을 고르려면: `run-hw-test.bat -Only H-25,H-13`, 묶음은 `run-hw-test.bat -Plan 3`, 자동 검사만은 `run-hw-test.bat -AutoOnly -Plan 2`.

### 다른 노트북에서 (정전·손님 와이파이·가짜 서버)

POS기가 꺼지는 시험은 POS기에서 잴 수 없으니 같은 공유기의 노트북에서 POS기를 가리켜 돌립니다.

```
run-hw-test.bat -Server http://192.168.0.10:8090 -Only H-1
run-hw-test.bat -Only H-8      (손님 와이파이에 붙인 노트북. POS기·TV 주소를 묻습니다)
```

## 결과

```
hw-test\results\20261130-1012-POS01\
  run.json        모든 단계의 결과(이어 하기도 이 파일로)
  report.md       사람이 읽는 보고서 (끝나면 메모장으로 열림)
  evidence\       POS 화면(png), TV 캡처(jpg), logcat, getprop, 서버 로그, CSV(부하·72시간 기록)
hw-test\results\20261130-1012-POS01.zip   ← 끝까지 마치면 만들어짐
```

`report.md` 에는 다음이 들어 있습니다.

- **항목별**: 항목마다 통과·실패·건너뜀 수와 판정
- **실패**: 단계, 한 일, 합격 기준, 실제 결과, 메모, 증거 파일 링크, 관련 위험 번호
- **위험 점검표 상태 칸에 넣을 값**: `| H-25 | 실패 11/30(③ 60초 넘게 안 뜸) — docs/hw-test/results/… |` 처럼 점검표 H 표에 그대로 옮길 값
- **개발 스레드에 보낼 글**: 실패를 한 줄씩 정리한 글(그대로 붙여 넣기)

### 실패를 넘기는 법

압축 파일(`results\….zip`)을 Claude 프로젝트 스레드에 올리고 "시험 결과 반영해 줘"라고 하면, 결과를 `docs/hw-test/results/` 에 넣고 위험 점검표 H 상태를 고치고, 실패를 해당 개발 스레드(TV 앱, 서버, 설치 묶음, 키패드 앱)로 넘깁니다. 직접 하려면 `report.md` 의 마지막 두 절을 복사하면 됩니다.

`report.md` 만 다시 만들려면: `run-hw-test.bat -Report results\20261130-1012-POS01`

## 주의

- 번호 부르기 검사(H-9, H-11, H-16, H-28, H-29, H-5)는 **시험 번호(900번대·9000번대)를 실제로 부릅니다**. TV에 뜨니 영업 중인 매장에서는 돌리지 말고, 끝나면 수정 화면의 '전체 지우기'로 지웁니다.
- H-25 ③(서버 강제 종료)과 H-28은 서버를 끕니다. 묻는 창에서 `y` 를 눌러야 진행합니다.
- 이 시험이 연 A/S 연결(adb)은 끝날 때 잠글지 묻습니다(기본 잠금).
- 비밀번호는 메모리에만 두고 결과 파일에 쓰지 않습니다. 결과 파일에는 TV 이름·IP·모델, POS기 사양이 들어갑니다.
- H-25·H-26·H-27·H-28·H-29와 A/S 연결을 A/S 관리자만 여는 동작은 설치 묶음 PR(#11)이 들어간 서버 기준입니다. 그 전 서버에서는 해당 자동 검사가 '실패'(작업·방화벽 없음)로 나옵니다.

## 시험 항목 고치기

1. `hw-tests.json` 을 고칩니다. 단계 필드: `n`(단계 번호), `do`(할 일), `expect`(합격 기준), `auto`(자동 검사 이름), `args`(검사 인자), `value`(`label`, `max`/`min`), `shot`(`pos`/`tv` 사진), `reboot`(POS기 다시 켜기).
2. `node check_hw_tests.js --write` 로 인쇄용 시험표를 다시 만들고, `node check_hw_tests.js` 로 검사합니다(번호 겹침, 없는 자동 검사, 위험 점검표의 H가 빠졌는지).
3. 새 자동 검사는 `hw-test.ps1` 의 `$script:Checks['이름'] = { param($a) ... return (Res 'pass' '설명') }` 로 더하고, `check_hw_tests.js` 의 설명 표에도 한 줄 넣습니다.
4. `hw-test.ps1` 은 **UTF-8(BOM 있음)** 으로 저장합니다. `.bat` 에는 한글을 넣지 않습니다.

## 자동 점검 (GitHub Actions)

`.github/workflows/hw-test.yml` 이 이 폴더가 바뀔 때 Windows(Windows PowerShell 5.1)에서 `ci-selftest.ps1` 을 돌립니다: `digital-menu` 아래 모든 `.ps1` 문법·BOM 검사, 임시 PocketBase 서버와 가짜 TV(2초마다 보고, 캡처 요청에 사진 올림)로 `hw-test.ps1 -SelfTest`(자동 검사·사람 묻기 흐름·보고서·압축). 실제 기기 판정은 하지 않습니다.
