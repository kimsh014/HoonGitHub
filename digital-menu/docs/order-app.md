# 번호 호출 키패드 앱 (MenuBoardKeypad)

1차(12/15) 번호 호출 방식에서 POS기에 까는 앱입니다. 번호표는 판매 프로그램·키오스크가 이미 찍는 주문번호를 그대로 쓰고,
음식이 나오면 직원이 USB 숫자 키패드로 **번호 + Enter**를 쳐서 TV 메뉴판에 번호를 띄웁니다.
준비 중 목록은 1차에 없습니다(주문서 출력 자동 읽기는 첫 업데이트).

## 직원이 쓰는 법

| 하고 싶은 것 | 키패드 | 창의 단추 |
| --- | --- | --- |
| 번호 부르기 | `1` `2` `Enter` | 숫자 → 부르기 |
| 다시 부르기(TV가 다시 깜빡임) | `+` `1` `2` `Enter`, 맨 앞 번호면 `+` `Enter` | 아래 번호 목록에서 번호 → "12번 다시" |
| 잘못 부른 번호 TV에서 빼기 | `-` `1` `2` `Enter`, 방금 부른 번호면 `-` `Enter` | 번호 목록에서 번호 → "12번 빼기" |
| 한 자리 지우기 | `.` (Del) | ⌫ |
| 입력 모두 지우기 | `*` 또는 `/` | 지움 |

- 확인이 필요한 경우(창에 주황 글씨, 경고음): 최근 번호와 30 넘게 떨어진 번호(예: 101 다음 201), 이미 TV에 떠 있는 번호. **Enter를 한 번 더** 누르면 부르고, 틀렸으면 `.`로 고칩니다. 8초 안에 안 누르면 다시 묻습니다.
- 3초 안에 같은 번호를 또 치면 한 번만 띄웁니다.
- 숫자를 치다 10초 손을 떼면 입력이 지워집니다.
- Num Lock 불이 꺼져 있어도 그대로 됩니다(창에 "Num Lock 꺼짐" 표시만 나옴).
- 서버에 못 보냈으면 빨간 글씨와 함께 번호가 입력 칸에 남습니다. 서버가 돌아오면 **Enter**만 누르면 다시 보냅니다.
- 창 닫기(X)는 최소화입니다. 최소화되어 있어도 키패드는 받고, 키를 누르면 창이 다시 나타납니다.

## 설치 (POS기, Windows 10 Pro)

1. 메뉴판 서버를 먼저 설치합니다(`docs/install-pos.md`).
2. `order-app` 폴더를 POS기에 복사합니다(예: `C:\MenuBoard\order-app`). 서버 묶음 옆에 두면 됩니다.
3. **판매 프로그램을 쓰는 Windows 계정**으로 로그인한 채 `install-order-app.bat`을 더블클릭하고 '예'를 누릅니다.
   - Windows 기본 `csc.exe`로 `MenuBoardKeypad.exe`를 빌드합니다(인터넷 필요 없음).
   - 작업 스케줄러에 `MenuBoardKeypad`(로그인할 때, 가장 높은 권한, 시간 제한 없음)를 등록하고 바로 켭니다.
4. 처음 뜨면 설정 창이 열립니다. 수정 화면(`http://127.0.0.1:8090/admin.html`) 맨 아래 **POS·키오스크 연동**의 키(`mbpos_…`)를 붙여 넣고 **연결 확인** → **저장**.
   - 키오스크나 POS 연동에 이미 쓰는 키가 있으면 **같은 키**를 넣습니다. 키를 새로 만들면 예전 키를 쓰던 기기가 바로 막힙니다.
5. 키패드로 `1` `Enter`를 쳐서 TV에 1번이 뜨는지, `-` `Enter`로 빠지는지 봅니다.

없애기: `install-order-app.bat --uninstall`. 설정(암호화된 키 포함)은 `%APPDATA%\MenuBoard\keypad.ini`, 기록은 `%LOCALAPPDATA%\MenuBoard\keypad.log`(1MB씩 2개)에 있습니다.

### 설정 창

| 항목 | 기본 | 설명 |
| --- | --- | --- |
| 메뉴판 서버 주소 | `http://127.0.0.1:8090` | 서버가 다른 PC에 있으면 그 주소 |
| POS 연동 키 | 없음 | Windows 데이터 보호(DPAPI, 이 사용자)로 암호화해 저장. 화면·기록에 원문을 남기지 않음 |
| 숫자패드 키를 이 앱이 받기 | 켬 | 끄면 키패드는 판매 프로그램으로 가고, 번호는 창의 단추로만 부름 |
| 항상 위에 두기 | 켬 | 5초마다 다시 맨 위로(포커스는 빼앗지 않음) |
| 소리 | 켬 | 부름(딩)·경고·오류 소리 |
| 멀리 떨어진 번호 확인 | 30 | 0이면 묻지 않음 |
| 앱 끝내기 | | 확인 후 끝냄. 다음 로그인 때 다시 켜짐 |

## 만든 방식과 이유

- **Windows 10 기본 .NET Framework 4.8 + WinForms, exe 하나**: 납품 POS(i3-6006U, Windows 10 Pro)에 따로 깔 것이 없고(웹뷰·런타임 설치 없음), 판매 프로그램 옆에서 가볍습니다(메모리는 현장 시험 K-12에서 잰다). 소스는 C# 5 문법만 써서 POS기 안의 `csc.exe`로도 빌드됩니다.
- **판매 프로그램에 포커스가 있어도 키패드 받기**: 저수준 키보드 훅(`WH_KEYBOARD_LL`)으로 숫자패드 키를 **스캔 코드**로 골라 받고 삼킵니다. 그래서 Num Lock과 상관없고, 숫자가 판매 프로그램 입력칸에 새어 들어가지 않습니다. 화상 키보드 같은 프로그램이 만든 키는 건드리지 않습니다.
- **포커스를 빼앗지 않는 창**(`WS_EX_NOACTIVATE`): 창의 단추를 눌러도 판매 프로그램 입력이 끊기지 않습니다.
- **지킴이**: 작업 스케줄러는 `MenuBoardKeypad.exe`(창 없는 지킴이)를 켜고, 지킴이가 `--app`으로 번호 창을 켭니다. 번호 창이 오류·강제 종료로 꺼지면 2초 뒤 다시 켭니다(1분에 5번 넘으면 30초 쉼). 설정의 '앱 끝내기'만 지킴이까지 멈춥니다.
- **서버와의 약속**: 매장 계정 로그인 대신 POS 연동 키로 `/api/menuboard/pos/calls`를 부릅니다. 로그인 만료(B-12)와 상관없습니다. 앱은 상태를 따로 갖지 않고, 3초마다 TV 번호 목록을 받아 연결 상태와 목록을 보입니다(매장 안 127.0.0.1이라 부담이 거의 없음).

## 한계 (알고 쓰기)

- **키보드를 장치별로 구별하지 못합니다.** Windows 사용자 모드 훅은 키가 어느 키보드에서 왔는지 모릅니다. POS기에 숫자패드가 달린 일반 키보드를 꽂아 판매 프로그램에 숫자를 넣는 매장이면, 그 숫자패드도 이 앱이 가져갑니다. 그런 매장은 설정에서 '숫자패드 받기'를 끄고 창의 단추로 부르거나, 일반 키보드의 위쪽 숫자 줄을 쓰게 안내합니다. 장치별 구별은 커널 필터 드라이버가 있어야 해서 1차에서 뺐습니다.
- 판매 프로그램이 관리자 권한으로 돌면, 이 앱도 가장 높은 권한으로 돌아야 키를 받습니다(설치가 그렇게 등록함). 설치한 Windows 계정과 판매 프로그램을 쓰는 계정이 다르면 키를 못 받을 수 있습니다.
- 판매 프로그램이 자기 창을 항상 위·전체 화면으로 계속 올리면 서로 위로 올라가려 할 수 있습니다. 창을 화면 구석(오른쪽 아래)에 두면 결제 창을 가리지 않습니다. 창은 끌어서 옮길 수 있고 위치를 기억합니다.
- 번호는 1~9999. 4자리를 넘는 주문번호를 찍는 판매 프로그램은 뒤 4자리만 쓰도록 안내가 필요합니다(아직 그런 사례 없음).

## 현장 시험 항목 (12/1~ 하드웨어 시험, 클라우드에서 못 해 본 것)

클라우드에서는 리눅스 mono로 C# 5 빌드와 키패드 규칙 검사(`tests/run-tests.sh`), 서버 경로 검사(`server/check_calls.js`), 서버와 실제 HTTP 주고받기만 확인했습니다. 아래는 POS기에서만 확인됩니다.

| 번호 | 확인할 것 | 기대 |
| --- | --- | --- |
| K-1 | `install-order-app.bat`이 Windows 10 Pro 기본 상태에서 빌드·등록·실행 | 창이 오른쪽 아래에 뜨고 처음이면 설정 창 |
| K-2 | 판매 프로그램 입력칸에 커서가 있을 때 키패드 `12` `Enter` | TV에 12, 판매 프로그램 칸에는 아무것도 안 들어감 |
| K-3 | Num Lock 끈 채로 K-2 | 똑같이 됨, 창에 "Num Lock 꺼짐" |
| K-4 | 판매 프로그램을 관리자 권한으로 띄운 채 K-2 | 똑같이 됨 |
| K-5 | 키패드 기종 3가지 이상(유선·무선 동글·`00` 키 있는 것) | 모든 숫자·Enter·`+` `-` `.` 동작, `00`은 0 두 번 |
| K-6 | 창의 단추를 눌러도 판매 프로그램 입력칸의 커서가 그대로인지 | 포커스 안 뺏김 |
| K-7 | 작업 관리자에서 번호 창 강제 종료 | 2초 뒤 다시 뜸 |
| K-8 | POS기 재부팅·자동 로그인 | 로그인 뒤 창이 저절로 뜸 |
| K-9 | 서버 끈 상태에서 번호 부르기 → 서버 켠 뒤 Enter | 빨간 안내, 번호가 입력 칸에 남고 Enter로 다시 보내짐 |
| K-10 | 1366×768, 1024×768, 125% 배율 화면 | 창이 잘리지 않고 글자가 흐리지 않음 |
| K-11 | 판매 프로그램 결제 창(카드 단말 대기)과 겹칠 때 | 결제 창을 가리지 않는 위치로 옮겨 두면 기억함 |
| K-12 | 하루 영업(8시간 이상) 동안 켜 둠 | 키패드가 계속 동작(훅이 떨어지지 않음), 기록에 오류 없음, 메모리 50MB 이하 |
