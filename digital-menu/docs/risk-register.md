# 매장 운영 위험 점검표

이 파일이 위험 점검표의 기준본입니다. 새 코드가 들어올 때마다 `/menu-risk`(위험 점검단 4명)가 이 파일을 갱신합니다.
처음 내용은 Claude 문서 "매장 운영 위험 점검표 (병합 전)"(2026-11-26)에서 옮겼습니다.

- **위험도:** 영업에 주는 피해 (높음 / 중간 / 낮음)
- **가능성:** 매장 100곳에 깔았을 때 얼마나 자주 생길지의 추정 (높음 / 중간 / 낮음 / 확실 / 확인 필요)
- **시기:** 1차(12/15 출시 전) / 이후
- **상태:** 열림 / 대응 중 / 해결(근거) / 실기기 확인 필요 / 닫음(이유)
- **담당:** 운영 = `menu-risk-ops`, 실수 = `menu-risk-mistakes`, 보안 = `menu-risk-security`, 현장 = `menu-risk-field`

새 항목 번호는 분류 글자를 그대로 이어 씁니다(B-11, M-23, R-7, C-10, H-13). 지운 번호는 다시 쓰지 않습니다.
