# 매장 POS기 설치 안내서 (디지털 메뉴판 서버)

설치 기사가 매장에서 위에서부터 순서대로 따라 하는 안내서입니다. 설치 중에는 인터넷이 필요 없습니다.

- POS기: Windows 10 또는 11. 메뉴판 서버가 이 PC에서 창 없이 늘 돌고, TV(보드)가 같은 공유기를 거쳐 이 PC에 붙습니다.
- 서버 주소: POS기에서는 `http://127.0.0.1:8090`, TV에서는 `POS기주소:8090`(예: `192.168.0.10:8090`).
- 메뉴 수정 화면: `http://127.0.0.1:8090/admin.html` · TV 관리 화면: `http://127.0.0.1:8090/devices.html`
- 메뉴판 화면: `http://127.0.0.1:8090/?screen=화면번호&zoom=글자배율` (예: `?screen=1&zoom=100`). 한 서버에 매장이 여럿이면 끝에 `&store=매장번호`를 붙입니다.

---

## 0. 준비물

1. 배포 묶음 USB. 안에 다음이 있어야 합니다.
   - `server` 폴더: `pocketbase.exe`, `pb_migrations`, `pb_hooks`, `pb_public`, `install-server.bat`, `install-server.ps1`, `run-server.ps1`, `uninstall-server.bat`, `start-server.bat`
   - `board-app` 폴더: `menuboard-player.apk`, `install-board-app.bat`
   - `order-app` 폴더: `src`, `build.bat`, `install-order-app.bat`, `install-order-app.ps1` (번호 호출 키패드 앱)
   - `server` 폴더 안에 `pb_data` 폴더나 `.dev-`로 시작하는 파일이 **있으면 안 됩니다**(다른 매장의 데이터·개발용 비밀번호). 있으면 설치하지 말고 묶음을 만든 사람에게 알립니다.
2. POS기의 Windows 관리자 계정 비밀번호.
3. 공유기 관리자 화면에 들어갈 수 있는 비밀번호(고정 IP를 잡을 때).
4. A/S 기록지(관리자 비밀번호를 옮겨 적을 곳).
5. "공유기·인터넷 바꾸기 전 A/S 문의" 스티커, POS기에 붙일 "아침에 전원만 켜면 메뉴판이 저절로 뜹니다" 스티커.

## 1. 서버 설치

납품 POS기는 **Windows 10 Pro** 기준입니다. 설치 전에 C 드라이브 빈 공간이 **10GB 이상**인지 봅니다(매일 자동 백업 7개와 손 백업 3개가 사진까지 통째로 쌓입니다).

1. USB의 `server` 폴더를 POS기의 `C:\MenuBoard\` 안에 복사합니다. 결과가 `C:\MenuBoard\server\pocketbase.exe` 가 되게 합니다.
   - 다른 위치에 두어도 동작하지만, A/S 때 찾기 쉽게 매장마다 같은 위치를 씁니다. 바탕 화면이나 다운로드 폴더는 쓰지 않습니다.
2. `C:\MenuBoard\server\install-server.bat` 을 더블클릭합니다.
3. "사용자 계정 컨트롤" 창이 뜨면 **예**를 누릅니다.
   - 창이 뜨지 않고 "관리자 권한을 얻지 못했습니다"가 나오면, `install-server.bat` 을 마우스 오른쪽 단추로 눌러 **관리자 권한으로 실행**을 누릅니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
4. `빠른 시작을 끌까요?` 가 나오면 `Y` 를 누르고 Enter 를 누릅니다(권장. 그냥 Enter 도 `Y`).
5. 창 아래쪽 결과를 봅니다.
   - `TV(보드)에 넣을 서버 주소` 아래의 `192.168.x.x:8090` 을 적어 둡니다.
   - 노란 글씨 `A/S 관리자 계정` 의 이메일과 비밀번호를 A/S 기록지에 옮겨 적습니다.
   - `확인할 것` 이 나오면 그 내용을 이 안내서 맨 아래 "문제 해결"에서 찾습니다.
6. 아무 키나 눌러 창을 닫습니다. 창을 닫아도 서버는 계속 돕니다.
7. 파일 탐색기에서 `C:\MenuBoard\server\AS-관리자-비밀번호.txt` 를 지웁니다(관리자 권한을 물으면 **계속**).
   - 이 파일은 관리자만 열 수 있게 되어 있습니다. 비밀번호는 A/S 기록에만 남깁니다.

`install-server.bat` 이 하는 일(다시 실행해도 됩니다. 메뉴 데이터는 그대로입니다):

| 하는 일 | 내용 |
| --- | --- |
| 자동 실행 | 작업 스케줄러에 `MenuBoardServer` 작업을 만듭니다. 컴퓨터가 켜지면 로그인하지 않아도 SYSTEM 계정으로 창 없이 서버가 뜹니다. 서버가 꺼지면 5초 뒤 다시 켜고, 작업 자체가 실패하면 1분마다 다시 시작합니다. |
| 로그 | `C:\MenuBoard\server\logs\server-날짜.log`. 하루 한 파일, 14일 지나면 지웁니다. |
| A/S 관리자 계정 | `as@poswing.local` 계정을 설치마다 다른 24자 무작위 비밀번호로 만듭니다. 이미 있으면 그대로 둡니다. |
| 방화벽 | 8090 포트(TCP)를 같은 공유기 안(LocalSubnet)에서만 들어오게 엽니다. 인터넷 쪽에서는 못 들어옵니다. |
| 절전 | 전원이 연결되어 있을 때 절전·최대 절전·하드디스크 끄기를 "안 함"으로 합니다. |
| Windows 업데이트 | 사용 시간(이 시간에는 업데이트로 다시 시작하지 않음)을 7시 ~ 24시로, 로그인해 있는 동안 자동 재시작 안 함 정책도 넣어 맞춥니다. |
| 백신 | Windows Defender 검사 예외에 `C:\MenuBoard\server` 를 넣습니다. |

## 2. 설치 확인

1. POS기 브라우저 주소창에 `http://127.0.0.1:8090/admin.html` 을 넣고 Enter 를 누릅니다.
2. 메뉴 수정 화면(로그인 칸과 "첫 설치" 칸)이 보이면 됩니다.
   - 새 매장이면 "첫 설치 (계정이 하나도 없을 때만)" 에서 매장 이름, 사장님 이메일·비밀번호를 넣고 **위 이메일·비밀번호로 계정 만들기**를 누릅니다. 이 비밀번호는 사장님이 정하고, 기사가 기록하지 않습니다.
3. 주소창에 `http://127.0.0.1:8090/?screen=1&zoom=100` 을 넣고 메뉴판이 뜨는지 봅니다.
4. `Ctrl` + `Shift` + `Esc` 로 작업 관리자를 엽니다.
5. **세부 정보** 탭을 누릅니다.
6. `pocketbase.exe` 가 있고 사용자 이름이 `SYSTEM` 인지 봅니다.
7. 작업 표시줄에 메뉴판 서버 창(검은 창)이 **없는지** 봅니다. 있으면 그것은 `start-server.bat` 창이니 닫습니다.
8. POS기를 다시 시작합니다.
9. Windows 로그인 화면에서 **로그인하지 않고** 1분 기다립니다.
10. 다른 기기(TV 또는 같은 공유기에 붙은 휴대폰)의 브라우저에서 `http://POS기주소:8090/?screen=1` 을 엽니다. 메뉴판이 뜨면 자동 실행이 된 것입니다.
11. POS기에 로그인하고 1번처럼 수정 화면이 열리는지 다시 봅니다.

작업 스케줄러에서 보려면: 시작 메뉴에서 `작업 스케줄러` 를 엽니다 → 왼쪽 **작업 스케줄러 라이브러리** → 가운데 목록의 `MenuBoardServer` 의 상태가 **실행 중**이면 됩니다.

## 3. POS기 주소 고정 (공유기 DHCP 예약)

TV는 POS기 주소를 기억합니다. 공유기가 POS기에 다른 주소를 주면 TV가 서버를 다시 찾아야 하므로, 주소를 고정합니다. POS기에서 직접 고정 IP를 넣기보다 **공유기의 DHCP 예약**(주소 고정 할당)을 권장합니다(공유기를 바꿔도 충돌이 덜함).

1. 1단계 5번에서 적은 POS기 주소(예: `192.168.0.10`)를 확인합니다. 설치 창에 `자동 받은 주소 - 공유기에서 DHCP 예약을 하세요` 가 붙어 있었으면 이 단계를 꼭 합니다.
2. POS기 브라우저에서 공유기 관리 화면을 엽니다(ipTIME은 보통 `http://192.168.0.1`).
3. 공유기 관리자 비밀번호로 로그인합니다.
4. DHCP 서버 설정 화면에서 POS기 이름이나 주소를 찾아 "고정 할당"(ipTIME: **관리도구** → **고급 설정** → **네트워크 관리** → **DHCP 서버 설정**, 공유기마다 메뉴 이름이 다름)으로 등록합니다.
5. 저장을 누릅니다.
6. POS기를 다시 시작한 뒤 주소가 그대로인지 봅니다(`install-server.bat` 을 다시 실행해도 주소가 나옵니다).

방화벽은 같은 공유기 안(같은 서브넷)에서만 열려 있습니다. TV가 다른 공유기(공유기 두 대를 이어 쓰는 경우 등)에 붙어 있으면 서버에 못 붙습니다. TV와 POS기는 **같은 공유기**에 연결합니다.

## 4. 정전 뒤 자동으로 켜지게 (BIOS)

정전이 되었다가 전기가 들어오면 POS기가 스스로 켜지게 합니다. 그래야 서버도 자동으로 뜹니다.

1. POS기를 다시 시작하면서 BIOS 설정 키(보통 `Del`, `F2`, POS 제조사에 따라 다름)를 여러 번 누릅니다.
2. 전원 관련 메뉴에서 "전원 복구 시 켜짐" 항목을 찾습니다. 제조사마다 이름이 다릅니다: `Restore on AC Power Loss`, `AC Power Recovery`, `After Power Failure`, `AC Back` 등.
3. 값을 `Power On`(또는 `Always On`, `Last State`)으로 바꿉니다.
4. 저장하고 나옵니다(보통 `F10`).
5. 확인: 윈도우를 종료하지 않은 채 전원 플러그를 뽑았다 꽂아 POS기가 스스로 켜지는지 봅니다(매장 영업에 지장 없을 때만).

## 5. 백신 예외

Windows Defender는 설치 bat이 예외를 넣습니다. V3나 알약을 쓰는 매장은 Defender가 꺼져 있으므로 직접 넣습니다. 예외에 넣을 폴더는 `C:\MenuBoard\server` 입니다. 백신 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

**V3 (V3 Lite, V3 365 클리닉 등)**

1. 작업 표시줄 오른쪽 V3 아이콘을 두 번 누릅니다.
2. 오른쪽 위 **환경 설정**(톱니바퀴)을 누릅니다.
3. **검사 예외 설정**(또는 **예외 설정**)을 누릅니다.
4. **폴더 추가**를 누르고 `C:\MenuBoard\server` 를 고릅니다.
5. **확인** 또는 **적용**을 누릅니다.

**알약**

1. 작업 표시줄 오른쪽 알약 아이콘을 두 번 누릅니다.
2. **환경 설정**을 누릅니다.
3. **예외 설정**(**검사 예외** 또는 **예외 목록**)을 누릅니다.
4. **폴더 추가**를 누르고 `C:\MenuBoard\server` 를 고릅니다.
5. **적용** 또는 **확인**을 누릅니다.

예외를 넣은 뒤 POS기를 다시 시작하고 2단계 10번으로 확인합니다. 백신이 `pocketbase.exe` 를 치료(삭제)했으면 USB의 `server\pocketbase.exe` 를 다시 복사하고 `install-server.bat` 을 다시 실행합니다.

## 6. TV 연결과 화면 번호 확인

TV(보드) 앱 설치는 `board-app\install-board-app.bat` 을 씁니다(README "보드 앱 빌드와 설치" 참고).

1. TV를 켭니다. 메뉴판 앱이 같은 공유기의 서버를 스스로 찾아 메뉴판을 띄웁니다.
2. 못 찾으면 설정 화면이 뜹니다. **서버 주소 (POS기, 예: 192.168.0.10:8090)** 칸에 1단계 5번의 주소를 넣고 **저장하고 메뉴판 보기**를 누릅니다.
3. TV마다 화면 번호(1~4)가 맞는지 봅니다. 예: 카운터 왼쪽 TV = 1, 오른쪽 TV = 2.
   - TV에서 바꾸려면 메뉴판에서 리모컨 확인 버튼을 2초 누릅니다 → **화면 번호 (1~4)** 를 고칩니다 → **저장하고 메뉴판 보기**.
   - POS기에서 바꾸려면 `http://127.0.0.1:8090/devices.html` 에서 그 TV의 화면 번호를 고칩니다(15초 안팎 뒤 반영).
4. 화면 번호를 정했으면 TV 뒤나 아래에 번호를 적은 라벨을 붙이고, A/S 기록에 "TV 위치 = 화면 번호"를 적습니다.
5. 같은 화면 번호를 두 TV가 쓰고 있지 않은지 `devices.html` 목록에서 봅니다.

## 6-1. 번호 호출 키패드 앱

직원이 USB 숫자 키패드로 번호 + Enter를 치면 TV에 번호가 뜨게 하는 앱입니다. 자세한 것은 `docs/order-app.md`.

1. 먼저 사장님께 두 가지를 묻고 A/S 기록에 적습니다.
   - 판매 프로그램에 **POS기 키보드의 숫자패드**로 금액·수량을 넣는지. 넣는다면 7번에서 '숫자패드 받기'를 끄고 창의 단추로 부르게 안내합니다(키패드 앱이 숫자패드를 가져가기 때문).
   - **바코드 스캐너**가 있는지, 숫자패드·Alt 방식인지. 그 방식이면 일반 키보드 방식으로 바꿉니다.
2. 키패드는 **유선** USB 숫자패드를 기본으로 씁니다(무선은 시험을 통과한 기종만). 키패드 자리에서 POS 화면이나 TV 번호 화면이 보이는지, POS 소리가 켜져 있는지 봅니다. 안 보이면 "치고 나서 TV 확인" 스티커를 붙입니다.
3. USB의 `order-app` 폴더를 `C:\MenuBoard\order-app` 으로 복사합니다.
4. **판매 프로그램을 쓰는 Windows 계정으로 로그인한 채** `C:\MenuBoard\order-app\install-order-app.bat` 을 더블클릭하고, 사용자 계정 컨트롤 창에서 **예**를 누릅니다.
5. 결과에 나온 계정이 판매 프로그램을 쓰는 계정인지 봅니다. `[주의] ... 관리자 계정이 아닙니다` 가 나오면 A/S 기록에 적습니다.
6. 오른쪽 아래에 번호 창과 설정 창이 뜹니다. 수정 화면(`admin.html`) 맨 아래 **POS·키오스크 연동**에서 키를 넣습니다.
   - 키오스크·POS 연동에 이미 쓰는 키가 있으면 **같은 키**를 넣습니다. 새로 만들면 예전 키를 쓰던 기기가 바로 끊깁니다.
   - **연결 확인** → "연결됨: 매장 이름"이 나오면 **저장**.
7. 판매 프로그램을 띄우고 입력칸에 커서를 둔 채 키패드로 `1` `Enter` 를 칩니다. TV에 1번이 뜨고, 판매 프로그램 칸에는 아무것도 안 들어가야 합니다. `-` `Enter` `Enter` 로 1번이 빠지는지 봅니다.
8. 번호 창을 결제 창을 가리지 않는 자리로 끌어 둡니다(위치를 기억함).

## 7. 매장 네트워크와 리모컨

1. **손님 와이파이 분리**: 공유기의 "게스트 네트워크"(ipTIME: **무선 설정/보안** → **게스트 네트워크**)를 켜서 손님은 그쪽에만 붙게 합니다. 손님이 POS기·TV와 같은 망에 붙으면 메뉴판 서버에 들어올 수 있습니다. 매장 와이파이 비밀번호는 손님에게 알려 주지 않습니다.
2. TV는 되도록 랜선으로, 와이파이를 쓸 때는 매장용(손님용이 아닌) 와이파이에 붙입니다.
3. **TV 리모컨 보관**: TV 리모컨은 카운터 안쪽에 보관하도록 사장님께 말씀드립니다(손님이 메뉴판 앱을 끄거나 설정을 바꾸지 않게).
4. **공유기 스티커**: 공유기에 "바꾸기 전 A/S 문의" 스티커를 붙입니다. 공유기를 바꾸거나 초기화하면 주소 예약이 사라져 TV가 서버를 못 찾을 수 있습니다.

## 8. 백업과 되돌리기

메뉴·계정·사진은 모두 `C:\MenuBoard\server\pb_data` 폴더에 있습니다.

- **자동 백업**: 서버가 매일 백업을 `C:\MenuBoard\server\pb_data\backups` 에 만들고 최근 7개를 남깁니다(서버 쪽 작업이 들어간 뒤부터).
- **백업에서 되돌리기**:
  1. POS기 브라우저에서 `http://127.0.0.1:8090/_/` 를 엽니다.
  2. A/S 기록의 `as@poswing.local` 과 비밀번호로 로그인합니다.
  3. 왼쪽 **Settings** 를 누릅니다.
  4. **Backups** 를 누릅니다.
  5. 되돌릴 날짜의 백업 줄에서 **Restore** 를 누릅니다.
  6. 확인 창에서 백업 이름을 그대로 입력하고 확인을 누릅니다. 서버가 잠깐 다시 켜집니다.
- **손으로 백업(폴더 복사)**:
  1. 시작 메뉴에서 `cmd` 를 찾아 마우스 오른쪽 단추 → **관리자 권한으로 실행**을 누릅니다.
  2. `schtasks /end /tn MenuBoardServer` 를 입력하고 Enter 를 누릅니다(서버 끄기).
  3. 작업 관리자 **세부 정보** 탭에 `pocketbase.exe` 가 없는지 봅니다. 있으면 그 줄을 골라 **작업 끝내기**.
  4. `C:\MenuBoard\server\pb_data` 폴더를 USB에 통째로 복사합니다.
  5. `schtasks /run /tn MenuBoardServer` 를 입력하고 Enter 를 누릅니다(서버 켜기).
- **폴더 복사본으로 되돌리기**: 위 1~3번으로 서버를 끕니다 → `pb_data` 폴더 이름을 `pb_data-예전` 으로 바꿉니다 → USB의 `pb_data` 를 `C:\MenuBoard\server\` 에 복사합니다 → 위 5번으로 서버를 켭니다.
  - 서버가 켜진 채로 `pb_data` 를 복사하면 복사본이 깨질 수 있습니다. 꼭 끄고 복사합니다.
- **POS기 교체**:
  1. 예전 POS기에서 위 1~3번으로 서버를 끕니다.
  2. `C:\MenuBoard\server` 폴더를 `pb_data` 까지 **통째로** USB에 복사합니다.
  3. 예전 POS기에서 `uninstall-server.bat` 을 실행합니다.
  4. 새 POS기의 `C:\MenuBoard\` 에 그 `server` 폴더를 붙여 넣습니다.
  5. 새 POS기에서 1단계 2번부터 따라 합니다. A/S 관리자 계정은 이미 있으므로 비밀번호는 예전 그대로입니다.
  6. 공유기 DHCP 예약을 새 POS기에 예전과 같은 주소로 다시 잡습니다(3단계). 주소가 달라지면 TV는 같은 매장 서버를 다시 찾아 붙지만, 몇 분 걸릴 수 있습니다.
  7. 번호 호출 키패드 앱을 6-1단계대로 새 POS기에 다시 설치합니다. 연동 키는 Windows 계정마다 암호화되어 옮겨 가지 않으므로 수정 화면의 키를 다시 넣습니다(새로 만들지 말고 A/S 기록의 키를 씁니다. 기록이 없으면 새로 만들고 키오스크에도 다시 넣습니다).
  8. 예전 POS기에서 `C:\MenuBoard\order-app\install-order-app.bat --uninstall` 을 실행합니다.

## 9. 비밀번호를 잊었을 때

- **사장님(메뉴 수정 화면) 비밀번호**: POS기에서 `http://127.0.0.1:8090/reset.html` 을 열어 다시 정합니다. POS기에서만 됩니다. 바꾸면 그 계정으로 로그인해 있던 폰·PC는 모두 로그아웃됩니다.
- **A/S 관리자 비밀번호**: POS기에서 `install-server.bat --reset` 으로 새로 만듭니다.
  1. 시작 메뉴에서 `cmd` 를 찾아 마우스 오른쪽 단추 → **관리자 권한으로 실행**.
  2. `cd /d C:\MenuBoard\server` 를 입력하고 Enter.
  3. `install-server.bat --reset` 을 입력하고 Enter.
  4. 새 비밀번호를 A/S 기록에 옮겨 적고, `AS-관리자-비밀번호.txt` 를 지웁니다.

## 10. 점검할 때 (창을 띄워 서버 보기)

- 서버 로그: `C:\MenuBoard\server\logs\server-오늘날짜.log` 를 메모장으로 엽니다.
- 서버를 창으로 띄워 보려면 먼저 관리자 `cmd` 에서 `schtasks /end /tn MenuBoardServer` 로 자동 실행 서버를 끄고, 작업 관리자에서 `pocketbase.exe` 가 남아 있으면 **작업 끝내기**를 누른 뒤 `start-server.bat` 을 더블클릭합니다(관리자 권한을 묻으면 **예**). 점검이 끝나면 그 창을 닫고 `schtasks /run /tn MenuBoardServer` 로 다시 켭니다(또는 POS기 다시 시작).
- 자동 실행 서버가 도는 중에 `start-server.bat` 을 켜면 8090 포트가 겹친다는 경고가 나옵니다.
- 설치 뒤 서버 폴더는 관리자만 고칠 수 있습니다. `pb_public` 같은 파일을 바꿀 때는 관리자 권한을 묻는 창에서 **계속**을 누르거나, 새 배포 묶음으로 `install-server.bat` 을 다시 실행합니다.
- TV의 A/S 연결은 POS기에서 `http://127.0.0.1:8090/devices.html` 을 열어 A/S 관리자 계정으로 엽니다. 기사 폰에서 열면 관리자 비밀번호가 매장 와이파이로 암호화 없이 갑니다.

## 11. 제거

1. `C:\MenuBoard\server\uninstall-server.bat` 을 더블클릭하고 사용자 계정 컨트롤에서 **예**를 누릅니다.
2. 자동 실행 작업, 방화벽 규칙, Defender 예외가 지워지고 서버가 꺼집니다.
3. 메뉴 데이터(`pb_data`)는 남습니다. 완전히 지우려면 8단계처럼 `pb_data` 를 백업한 뒤 `C:\MenuBoard` 폴더를 지웁니다.
4. 절전 끄기, 업데이트 사용 시간, 빠른 시작 설정은 되돌리지 않습니다. 필요하면 Windows **설정**에서 직접 바꿉니다.
5. V3·알약 예외는 직접 지웁니다.

## 문제 해결

| 보이는 것 | 할 일 |
| --- | --- |
| `다른 프로그램이 8090 포트를 쓰고 있습니다` | 그 프로그램을 끄고 `install-server.bat` 을 다시 실행합니다. 다른 위치에 복사한 예전 메뉴판 서버면 그쪽 `uninstall-server.bat` 을 실행합니다. |
| `30초 안에 서버가 응답하지 않습니다` | `logs` 폴더의 오늘 로그를 봅니다. 백신이 `pocketbase.exe` 를 지웠는지(5단계) 봅니다. |
| `Defender 예외를 넣지 못했습니다` | V3·알약을 쓰는 매장입니다. 5단계대로 직접 넣습니다. |
| `업데이트 활성 시간을 넣지 못했습니다` 또는 Home 에디션 | **설정** → **Windows 업데이트**(Windows 10은 **업데이트 및 보안** → **Windows 업데이트**) → **사용 시간 변경**(Windows 11은 **고급 옵션** → **사용 시간**)에서 7시 ~ 24시로 직접 맞춥니다. 납품 POS기(Windows 10 Pro)는 설치 bat의 설정이 적용됩니다. 다른 에디션(Home)이면 적용되지 않을 수 있으니 이 화면에서 꼭 확인합니다. |
| TV가 "서버를 찾지 못했습니다" | TV와 POS기가 같은 공유기인지 봅니다 → POS기에서 `http://127.0.0.1:8090/?screen=1` 이 열리는지 봅니다 → 손님 와이파이에 붙어 있지 않은지 봅니다. |
| POS기 화면에 검은 서버 창이 떠 있음 | `start-server.bat` 창입니다. 닫습니다. 자동 실행 서버는 창이 없습니다. |
| 재부팅 후 TV가 메뉴판을 못 띄움 | 작업 스케줄러에서 `MenuBoardServer` 상태를 봅니다(2단계). **준비** 상태면 마우스 오른쪽 단추 → **실행**. 그래도 안 되면 `install-server.bat` 을 다시 실행합니다. |
