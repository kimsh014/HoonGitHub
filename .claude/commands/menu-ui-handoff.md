`menu-ui-handoff` 에이전트를 Agent로 불러 UI 작업 안내를 만든다. 대상: $ARGUMENTS (비었으면 `digital-menu/docs/ui-handoff/README.md`의 마지막 기준 이후 기본 브랜치 변경)

1. 에이전트에게 대상만 넘긴다.
2. 에이전트가 만든 안내 파일을 읽고 확인한다:
   - "AI에 붙여 넣을 작업 지시"가 그것만으로 일할 수 있는지(계약이 요약이 아니라 그대로 들어 있는지, 파일 이름·완료 기준이 있는지).
   - 비밀 정보(비밀번호, 키, 토큰, 내부 주소)가 없는지.
   - 바뀐 파일 분류가 `git diff --stat`과 맞는지.
   빠진 것이 있으면 에이전트에게 고칠 점을 넘겨 한 번 더 부른다.
3. 사용자에게 한국어로 짧게 보고한다: 만든 파일 경로, 백엔드·프론트엔드 변경 한 줄씩, UI 담당 할 일(필수 개수), 작업 지시를 UI 담당자에게 보내면 된다는 안내. 이 파일들을 커밋할지 묻는다(작업 브랜치가 따로 있으면 거기에 커밋하고 알린다).
